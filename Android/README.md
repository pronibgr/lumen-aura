# lumen aura — Android Port & Architecture

Этот каталог содержит полноценный порт **lumen aura** для платформы **Android** на базе **Avalonia UI** и **Android.Net.VpnService**.

---

## 📱 Архитектура и реализованный функционал

### 1. Адаптивный интерфейс: Смартфон vs Планшет
- **Смартфоны (ширина экрана < 720dp)**:
  - Точное соответствие предоставленному скетчу:
    - **Верхняя панель**: кнопка **Настройки** (шестерёнка) слева, кнопка **Добавления подписки** (`+`) справа. Боковое меню отсутствует.
    - **Главный экран**: большая округлая карточка с кнопкой включения/выключения питания (`Power`) и статусом подключения (`disconnected` / `connected`), плашка времени соединения `(время) Connection time: 00:00:00`, компактные индикаторы скорости (DL/UL/Data).
    - **Список подписок**: группировка по подпискам, раскрывающиеся списки серверов со статусом задержки/пинга (зеленый/желтый/красный/серый кружок), протоколом и контекстным меню.
    - **Настройки**: кнопка возврата (`← Назад`) с плавной физической анимацией слайда (`Slide + Fade`).
    - **Тема оформления**: выпадающий список (`ComboBox`) в настройках («Светлая» / «Тёмная»).
    - **Логи**: отдельная вкладка «Логи» прямо внутри подменю настроек.
- **Планшеты (ширина экрана ≥ 720dp)**:
  - Полное соответствие десктопному интерфейсу:
    - Боковая панель навигации (Rail) со свёрнутым/развёрнутым режимом.
    - Разделённая 2-колоночная область: слева список подписок и серверов с поиском и фильтрами, справа панель телеметрии с большой кнопкой подключения, детальными карточками скорости и активного узла.
    - Адаптированные touch-зоны (минимум 44–48dp) для удобного управления пальцами.

### 2. Полноценное системное туннелирование (Android VpnService)
Вся реализация выполнена **без заглушек и фейков**:
- **`AuraVpnService`** (`Android.Net.VpnService`):
  - Создаёт настоящий виртуальный сетевой интерфейс TUN (`172.19.0.1/30`, MTU `1500`, маршрут `0.0.0.0/0`, DNS `1.1.1.1` и `8.8.8.8`).
  - **Защита сокетов (`Protect()`)**: сокеты исходящих прокси-соединений защищаются через вызов `VpnService.Protect()`, что исключает зацикливание сетевого трафика.
  - **Фоновый сервис (Foreground Service)**: уведомление в шторке Android со статусом подключения, именем сервера и кнопкой быстрого отключения (`Disconnect`).
  - **Подсчёт трафика**: снятие реальных сетевых счетчиков (RX/TX байты) через `Android.Net.TrafficStats`.

### 3. Маршрутизация и раздельное туннелирование (Split-Tunneling)
- В отличие от ПК, где опрашиваются процессы операционной системы, на Android через `AndroidAppListProvider` опрашивается системный `PackageManager`:
  - Получение реального списка установленных приложений с их иконками, именами пакетов и отображаемыми названиями.
  - **Галочка «Показывать системные» (`ShowSystemApps`)**:
    - **Выключена** (по умолчанию): отображаются только пользовательские приложения (фильтрация по `(appInfo.Flags & ApplicationInfoFlags.System) == 0`).
    - **Включена**: отображаются все приложения, включая системные службы Android.
  - **Режимы маршрутизации**:
    - **Режим 0 (Весь трафик)**: весь сетевой трафик устройства направляется через VPN.
    - **Режим 1 (Bypass selected)**: трафик выбранных приложений пускается напрямую в обход VPN через нативный метод ядра Android `VpnService.Builder.AddDisallowedApplication(packageName)`.
    - **Режим 2 (Route ONLY selected)**: трафик ТОЛЬКО выбранных приложений заворачивается в VPN через `VpnService.Builder.AddAllowedApplication(packageName)`.

---

### 4. Плавная анимация тумблеров (ToggleSwitch) на всех платформах
- В `Styles/AppStyles.axaml` внедрены физические переходы:
  - Плавное скольжение бегунка переключателя с кривой ускорения `CubicEaseOut` (длительность 240 мс).
  - Плавная интерполяция цвета трека (`Background` и `BorderBrush`) и подложки.
  - Работает консистентно на Android, Linux, Windows и macOS.

## 🚀 Сборка и запуск на Android

### Требования
1. .NET 10 SDK (или .NET 9/8) с рабочей нагрузкой Android:
   ```bash
   dotnet workload restore Android/aura.Android.csproj
   # или
   dotnet workload install android
   ```
2. Android SDK (API 26+) и подключенное устройство / эмулятор Android.

### Сборка и установка APK
```bash
# Сборка Release APK
dotnet build Android/aura.Android.csproj -c Release

# Сборка и автоматический запуск на подключенном устройстве / эмуляторе
dotnet build Android/aura.Android.csproj -t:Run
```
APK файл будет сгенерирован по пути:
`Android/bin/Release/net10.0-android/com.lumen.aura-Signed.apk`
